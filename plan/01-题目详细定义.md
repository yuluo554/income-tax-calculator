## 一、项目介绍

每年个税汇算季与年终奖发放季，"我该补多少税""年终奖选单独计税还是并入综合所得""专项附加扣除到底能扣多少"是全民级痛点。现有网页计算器广告缠绕、计算过程不透明、**不给政策依据**，且政策年度间频繁变化（专项附加扣除 2023 年三项提标、年终奖单独计税政策延续至 2027 年底）导致旧工具结论过时。

本项目要求开发一款个人所得税联动计算器：**累计预扣法逐月计算引擎 + 年终奖计税方式择优（含临界区间警示）+ 七项专项附加扣除管理 + 社保公积金联动 + 年度汇算**，核心特色是**年度版本化规则集**（2019-2026 各年度税率表/减除费用/扣除标准打包为规则包，切换年度即切换规则，延续系列食品标签双标尺的 versioned ruleset 模式），每个结果数值旁挂政策文号与条款依据，全本地运行。

## 二、任务要求

### 1）累计预扣法逐月计算引擎

- 输入：月度工资、社保公积金个人部分、专项附加扣除、其他扣除；
- 按国家税务总局公告 2018 年第 61 号公式逐字实现：累计预扣预缴应纳税所得额 = 累计收入 − 累计免税收入 − 累计减除费用（5000 元/月 × 任职月份数）− 累计专项扣除 − 累计专项附加扣除 − 累计其他扣除；
- 输出逐月应预扣税额、累计应纳税所得额、适用预扣率级次；公式与税率表**挂 61 号公告条款**。

### 2）年终奖计税方式择优引擎（亮点）

- 单独计税（奖金 ÷12 查按月换算税率表）vs 并入综合所得，双方案对比并自动推荐；
- **临界区间警示**：由税率表机制性推导"多发一元、到手变少"的临界区间并标红提示（区间边界由规则集推导生成，不硬编码）；
- 依据：财政部 税务总局公告 2023 年第 30 号（单独计税政策执行至 2027-12-31，可择优）。

### 3）七项专项附加扣除管理

- 子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护；
- 规则化：扣除标准分档（婴幼儿照护/子女教育 2000 元/月、赡养老人独生 3000 元/月或分摊、租金与房贷利息**互斥**、大病医疗限额等）、分摊方式规则；
- 标准值逐项挂文号核对后入库：国发〔2018〕41 号暂行办法（原六项，2022 年增设婴幼儿照护成七项）+ 2023 年国务院提标通知（三项标准提高）。

### 4）社保公积金联动

- 缴费基数上下限、个人费率输入 → 个人部分计算并自动进入税前扣除链（与 1/3 联动）。

### 5）年度汇算

- 全年综合所得汇总（工资薪金+劳务报酬/稿酬/特许权使用费简化口径）→ 应纳税额 vs 已预缴 → 应退/应补税额，附汇算依据。

### 6）年度版本化规则集（工程亮点）

- 2019-2026 各年度规则包：减除费用、综合所得税率表、按月换算税率表、专项附加扣除标准、年终奖政策有效期（30 号公告至 2027-12-31）；切换年度即切换规则；规则包 JSON 化、每条挂文号与 status（未核对不得生效）。

### 7）内置评测基准（零 API 依赖）

- **官方/权威口径算例真值**：61 号公告算例、税务官方问答案例（逐条登记来源）；算例通过率 100%；
- **边界扫描**：税率级次临界点、年终奖陷阱区间边界、专项附加扣除互斥组合——程序化枚举验证与规则表自洽；零 API 依赖可重复，指标写进 README。

## 六、边界与非目标

- **不做**：经营所得、股权激励、财产租赁转让等复杂所得类型（扩展项）；不对接税务局接口、不做申报代办；不提供避税建议（临界区间提示仅为机制性事实呈现）。
- **合规红线**：全本地计算存储、零上传；**免责声明强制**：计算结果供参考，以税务机关核定为准；政策以发文机关正式文本为准，规则包未挂原文核对（status=待核对）不得生效。
- **数据纪律**：算例真值逐条登记来源（公告条文/官方问答 URL）；无来源数值不得作为基准真值。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
