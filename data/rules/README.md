# data/rules 年度规则包

年度版本化规则集（FR-6）：**切换年度即切换规则**。schema 定稿见 [plan/04 §一](../../plan/04-模块详设.md)。

## 纪律

1. 每个数值条目（含 `value` 键的节点）必带 `ref`（来源文号 + 条款）；`status` 缺失按"待核对"处理（宁缺勿错）；
2. `status=待核对` 的条目**不得参与计算结论**：加载器 `effective_ruleset()` 统一门控（"无出处数值不得生效"红线的代码化）；
3. 金额/税率统一 Decimal 语义；税率字段为字符串（如 `"0.03"`）；
4. 税率表固定 7 级、区间相接、末级上不封顶（`upper: null`）；
5. 修改规则包必须跑 `python -m pytest`（schema 与门控测试会同步验证）。
