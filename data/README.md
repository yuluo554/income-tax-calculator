## 三、已查渠道记录（官方成品算例检索）

真值库算例优先级目标为"官方发布成品算例"，实际检索结果：
- 61号公告正文与官方解读（广东税务转载快照）：**无数值算例**（解读仅有"5月入职减除费用按 5000/10000 元计"的口径说明）；
- 广东税务《全年一次性奖金个人所得税不同计税方式》（2023-11-01，含 50000 元→4790 元算例，搜索摘要在案）：Bing/DDG curl、广东局 search5 检索 API（`POST /search5/search/s` 已逆向可用）、WebSearch 四个通道均未定位到该文原文 URL，按纪律不采信摘要数值入真值库；
- gov.cn 政策文件库检索 API（`sousuo.www.gov.cn/search-gov/data`）无"解读"子库可查。

处置：真值库 4 条算例全部以**已核对官方文件数值 + 手工推导**构建（推导式逐条写入 note），来源挂规则文件官方 URL；M2 引擎以独立实现路径对账（plan/05 §1.3 双路对账思想）。M4 基准可再补官方算例（届时如定位到原文 URL 直接增补）。

## 五、法律与许可口径

- 规则包 JSON 中的条文信息为"条款号+要点"形式（规避全文转载），原文以官方 URL 为准；
- data/knowledge/raw/ 快照为官方公文（法律、行政法规、部门规章与规范性文件），依据《著作权法》第五条官方文件不适用版权保护，入库留档用于溯源；
- 真值库与规则包为本项目自制（固定输入可复现），MIT 许可随仓库发布。
